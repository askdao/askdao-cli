# internal/webstudio/
> L2 | 父级: ../../CLAUDE.md

本地 Web 工作台 —— `askdao agent edit` 拉起的 `127.0.0.1` HTTP server + `go:embed` 自包含前端。KOL 在浏览器审阅/编辑 Agent spec（profile + persona + 主题色）、按 scope 分组勾选 skill/MCP，点 Deploy/Done 一站式。写 yaml / deploy 由 cmd 层注入回调，webstudio **不依赖** pipeline/deploy。

## 成员清单

- **server.go** — `Options` / `Serve` / `Handler`（桌面长驻宿主复用 —— 同 Serve 路由但不「deploy 即退出」，供 Wails `AssetServer.Handler` 挂载）/ `openBrowser`。`net.Listen("tcp","127.0.0.1:0")` 随机端口；`go:embed studio.html` + `go:embed logo.png`；路由 `/`（HTML）+ `/logo.png`（AskDAO 品牌 logo，image/png）+ `/api/spec`(GET StudioData) + `/api/save`（写 yaml，不退出）+ `/api/deploy`（写 yaml + deploy，回 `DeployResult`{message/group_link/agent_id/created}，成功退出）+ `/api/done`（**Save & finish**：写 yaml + 退出，不 deploy；同 /api/save 调 OnSave 持久化编辑后退出）+ `/api/observe`（GET 读 observed 名单 / POST 收 Claude Code PreToolUse hook 上报，**始终 200 非阻塞**）+ **桌面 `/api/auth/*`**（status/login/poll/logout，仅当 Options 注入 `OnAuthState`/`OnLogin`/`OnLoginPoll`/`OnLogout` 回调时注册 —— CLI 不注入故无这些路由，`agent edit` 无感；配合 `StudioData.Desktop` + studio.html 顶部登录条）。`OnSave`/`OnDeploy` 回调注入，`OnReady(port)` 在 serve 后阻塞前回调（供 cmd 的 `--observe` 在起 claude 前写 hook settings）；包内 `observed`（RWMutex 守护的 skill/MCP server 运行时集合）+ `skillNameFrom`(R2 防御取名：skill→name→首字符串) / `mcpServerOf`(拆 `mcp__server__tool`)。`buildMux` 抽出供 httptest；`Serve` 阻塞至 deploy 成功或 done。
- **logo.png** — AskDAO 品牌 logo（512×512 RGBA），go:embed 进二进制，header 左上角 30px 圆角显示，与 askdao.ai topbar 一致。
- **api.go** — `StudioData`（含 `Observe` flag + `Desktop` flag（桌面 app 会话开关，前端据此条件渲染助手侧栏/测试聊天等桌面专属块；CLI `edit` 不置=默认 false，行为无感）+ `Icons` avatar 网格数据）/ `SkillCandidate` / `MCPCandidate` / `ObservedData`（`GET /api/observe` 的 `skills`+`mcp_servers` 名单）/ `DeployResult`（部署结构化结果：message + group_link + agent_id + created，group_link 独立字段供成功卡片渲染可点击按钮）/ `BuildStudioData(spec, det, harness, restorePrior)`。把 spec 草稿 + detection 候选摊平成前端 JSON。**勾选态二选一**：`restorePrior=true`（编辑已有 yaml）以 `spec.skills`/`mcp_servers` 为唯一真相 —— 忠实回显 KOL 上次选择（含默认本会漏掉的 stdio MCP），恢复表 key 镜像前端 `collect()` 序列化口径（builtin→id / custom_local→path / mcp→name）；`restorePrior=false`（全新草稿）走**默认策略**：project skill 全勾 / user(全局) skill opt-in 不勾 / implied builtin 勾 / Anthropic 兼容 MCP 勾、stdio 不勾。`Observe` 由 cmd 的 `--observe` 置位，前端据此显示观测区（叠加在勾选态之上，不改静态快照）。

## 设计约束

- **回调解耦**：webstudio 只管 HTTP + 序列化；写 yaml / deploy 业务由 cmd 注入 `OnSave`/`OnDeploy`，避免依赖 pipeline/deploy（单向依赖：cmd → webstudio）。
- **本地隐私**：绑 `127.0.0.1`（非 `localhost`，IPv4 确定避免 IPv6 ECONNREFUSED），数据只在本地，不上传文件内容。
- **无构建链**：studio.html 是 `go:embed` 静态资源，inline CSS/JS；字体走 Google Fonts CDN（联网时与品牌站视觉一致，离线 fallback Georgia/system），不引 npm/打包；契合项目 stdlib-only + 单二进制哲学。
- **风格对齐品牌站**：复用 AskDAO Kami Design System 的 token（color/font/radius/shadow/spacing），与品牌站视觉一脉相承；非独立创意美学。
- **scope 分组 + 默认勾选**：见 api.go —— user(全局)skill 默认不勾，避免 KOL 全局 skill 库被自动打包进每个 agent。
- **observe 是叠加层不是唯一真相**：`--observe` 观测到的项只做证据高亮 + 一键收窄建议，默认全勾保持为安全网；`observed` 是 server 运行时状态（非 `BuildStudioData` 静态快照），前端轮询叠加。临时 hook settings 的写入/合并/清理（零残留三件套）在 [../observe/CLAUDE.md](../observe/CLAUDE.md)；cmd 经 `OnReady(port)` 串联两者。
- **输入校验**（`validateStep`/`validateAll`/`showErrors`/`clearErrors`）：必填 = name + model_class（后端 required）+ display_name + description + system_prompt + vault secret name（产品要求）；name slug 格式 `^[a-z0-9]+(-[a-z0-9]+)*$`（≤64）。**Next 翻页拦当前 step + Deploy/finish 全量拦并跳第一个错误 step**；Save draft 宽松（仅 name 非空）。字段下 `.field-err` 红字 + 输入 `.invalid` 红框。对齐服务端校验契约；受控选择器（visibility/model radio、theme/avatar/category picker）天然合法不校验。
